# Owl & Crayon

A math and art app for kids, with an owl that answers questions in simple words. Works fully offline once opened.

- Source is in `src/` (`core.js` app, `math.js` curriculum, `art.js` art lessons). Run `python3 build.py` to regenerate `index.html` and `sw.js`.
- Try it locally: `python3 -m http.server`, then open http://localhost:8000.
- Every push to `main` publishes to GitHub Pages. On the tablet, open the site once and use "Add to Home Screen".

See [PLAN.md](PLAN.md) for the roadmap.
